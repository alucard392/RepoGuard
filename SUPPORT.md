# Support

## Questions and usage help

- Read the README and the in-app How to use guide first.
- For reproducible usage questions, open a GitHub Discussion if Discussions are enabled.
- For suspected bugs, use the Bug Report issue template.

## Before asking for help

Include RepoGuard version, Python version, operating system, scan mode, command or steps used, and sanitized output.

Never attach repositories containing private source code, credentials, personal data, or confidential files unless reviewed and sanitized. Do not post real tokens, passwords, private keys or environment files.

## Security reports

Do not report an exploitable secret-detection bypass in a public issue. Follow SECURITY.md and use private vulnerability reporting if enabled.
